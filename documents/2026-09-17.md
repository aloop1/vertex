# 회의록 (2026-09-17)

## 1. 회의 개요
- 프로젝트명: 크립 수명 예측을 위한 AI 솔루션
- 회의 목적: 앙상블 모델 성능 개선, 추가 데이터 활용성 및 KoMaP 경진대회 연계 방향 검토

## 2. 금주 진행 사항

### 2.1 앙상블 모델 성능 개선 및 개발 방향 검토
- 1학기 모델에서 Histogram Gradient Boosting과 RBF Regression 기반 앙상블 모델로 변경한 이후 예측 성능 지표가 0.83까지 향상된 결과를 정리함.
- 장재훈 교수님과의 면담을 통해 현재 모델의 성능을 추가로 높이는 방향으로 개발을 지속하기로 함.

### 2.2 추가 데이터 확보 및 활용 여부 논의
- 학습 데이터 보완을 위해 추가 데이터 제공 가능 여부를 문의하였으며, 다른 제품군의 데이터를 제공받을 수 있음을 확인함.
- 기존 데이터와 제품군이 달라 통합 학습의 적합성을 검토할 필요가 있으며, 데이터 추가 여부는 팀에서 판단하기로 함.

### 2.3 KoMaP AI 경진대회 참여 및 프로젝트 확장 방향 논의
- 장재훈 교수님으로부터 KoMaP AI 경진대회 참여를 권유받음.
- 대회에서 개발한 미세조직 이미지 분석 모델을 현재 프로젝트에 연계하는 방안을 제안받았으며, 크립 수명 예측과 미세조직 분석을 함께 제공하는 방향으로 기능 확장 가능성을 논의함.

## 3. 주요 의사결정 사항
- Histogram Gradient Boosting과 RBF Regression 기반 앙상블 모델의 추가 개선을 지속하기로 함.
- 다른 제품군 데이터는 입력 항목과 시험 조건을 비교한 뒤 통합 학습 여부를 결정하기로 함.
- KoMaP 경진대회용 미세조직 이미지 분석 모델과 크립 수명 예측 기능의 연계 가능성을 검토하기로 함.

## 4. 리스크 및 대응
- 리스크 1: 제품군이 다른 추가 데이터 통합으로 인한 분포 불일치
  - 대응: 변수, 시험 조건, 데이터 분포를 비교하고 별도 검증 후 활용 여부를 결정함.
- 리스크 2: 앙상블 모델 성능 개선의 한계
  - 대응: 동일한 검증 기준으로 오차를 분석하고 파라미터와 결합 비중을 조정함.
- 리스크 3: 미세조직 분석과 수명 예측 기능의 연계 복잡성
  - 대응: 이미지 모델의 입력과 출력 형식을 먼저 정의하고 필요한 데이터 조건을 구체화함.

## 5. 차주 계획

### 5.1 예측 모델 추가 개선
- 현재 앙상블 모델의 예측 오차를 분석하고 주요 파라미터와 결합 비중을 조정함.
- 동일한 검증 기준으로 개선 전후 결과를 비교하여 성능 향상 여부를 확인함.

### 5.2 추가 데이터 적용 가능성 검토
- 다른 제품군 데이터의 입력 항목과 시험 조건을 확인하고 기존 데이터와의 차이를 비교함.
- 크립 수명 예측 활용 가능성을 검토한 뒤 데이터 추가 여부와 활용 방식을 결정함.

### 5.3 KoMaP 경진대회 모델 연계 방안 구체화
- 미세조직 이미지 분석 모델의 입력과 출력 형식을 정리하고 현재 프로젝트에 적용할 수 있는 기능을 검토함.
- 이미지 분석 결과와 크립 수명 예측 결과를 함께 확인할 수 있는 화면 구성 및 연계에 필요한 데이터 조건을 논의함.
