# 회의록 (2026-10-09)

## 1. 회의 개요
- 프로젝트명: 크립 수명 예측을 위한 AI 솔루션
- 회의 목적: KoMaP 이미지 분할 모델 오류 분석 및 학습 설정 개선, 웹 기능 연동과 로컬 LLM 실행 환경 검토

## 2. 금주 진행 사항

### 2.1 KoMaP 이미지 분할 모델 오류 분석 및 학습 설정 개선
- 클래스별 IoU와 예측 마스크를 비교하여 분할 오류가 많은 상과 경계 영역을 중심으로 개선 작업을 진행함.
- 미세한 조직과 인접한 상이 혼동되는 부분을 검토하고, 데이터 증강 범위와 손실 가중치 등 학습 설정을 조정함.
- 겹치는 패치의 예측 결과를 통합하는 타일 추론과 테스트 시 증강(TTA)을 적용하여 예측의 일관성을 높이도록 구성함.

### 2.2 웹 기반 이미지 분할 기능 연동 및 결과 화면 보완
- 웹페이지에서 입력한 이미지를 분할 모델에 전달하고, 생성된 예측 마스크를 결과 화면에 표시하는 연동 작업을 진행함.
- 원본 이미지와 분할 결과를 함께 비교할 수 있도록 화면을 보완함.
- 이미지 입력부터 결과 표시까지의 처리 흐름을 점검함.

### 2.3 로컬 LLM 실행 환경 구성 및 응답 지연 개선 검토
- 높은 사양의 컴퓨터를 활용한 로컬 LLM 실행 환경 구성과 질의응답 화면 연결 작업을 진행함.
- 기존 환경에서 발생한 응답 지연을 개선하기 위해 모델 설정과 입력 문맥 길이를 검토함.
- 실행 환경 변경에 따른 응답 속도와 답변 품질의 비교를 진행함.

## 3. 주요 의사결정 사항
- 이미지 분할 모델은 조정한 학습 설정에 따른 클래스별 성능과 검증 결과를 바탕으로 사용할 모델을 선정하는 것으로 계획함.
- 차주 마감되는 대회 일정에 맞춰 보고서를 작성하고, 대회 진행에 차질이 없는지 점검하는 것으로 계획함.
- 웹 기반 이미지 분석 기능은 다양한 입력 상황에서 동작을 확인하고, 상태 표시와 입력 안내 및 결과 저장 과정을 보완하는 것으로 계획함.
- 변경한 로컬 LLM 실행 환경에서 RAG 연동을 검증하고, 전체 응답 시간과 답변의 적절성 및 출처 표시 여부를 확인하는 것으로 계획함.

## 4. 리스크 및 대응
- 리스크 1: 미세한 조직과 인접한 상의 혼동 및 경계 영역 분할 오류
  - 대응: 클래스별 IoU와 예측 마스크를 비교하고, 데이터 증강 범위와 손실 가중치를 조정하며 타일 추론과 TTA를 적용함.
- 리스크 2: 대회 마감 일정에 따른 최종 검증 및 보고서 작성 일정 점검 필요
  - 대응: 검증 결과를 바탕으로 사용할 모델을 선정하고, 차주 마감 일정에 맞춰 보고서 작성과 대회 준비 상태를 점검하는 것으로 계획함.
- 리스크 3: 다양한 이미지 크기와 입력 상황에서 웹 기능의 동작 및 결과 저장 검증 필요
  - 대응: 처리 중 상태 표시와 잘못된 입력 안내를 보완하고, 결과 확인 및 저장 과정의 오류를 점검하는 것으로 계획함.
- 리스크 4: 로컬 LLM 응답 지연 및 RAG 연동 시 답변 품질 검증 필요
  - 대응: 검색 자료 수와 입력 문맥 길이를 조정하고, 전체 응답 시간과 크립 관련 답변의 적절성 및 출처 표시 여부를 점검하는 것으로 계획함.
