# 회의록 (2026-09-05)

## 1. 회의 개요
- 프로젝트명: 크립 수명 예측을 위한 AI 솔루션
- 회의 목적: 크립 수명 예측 모델 성능 개선, 합금 설계 기능 개편 및 UI/UX 고도화 방향 점검

## 2. 금주 진행 사항

### 2.1 크립 수명 예측 모델 성능 개선 방향 논의
- 기존 Transformer와 Tree 기반 모델의 예측 성능을 분석하고, 크립 수명 예측 정확도 향상을 위한 모델 구조 개선 방향을 검토함.
- Histogram Gradient Boosting과 RBF Regression을 결합한 앙상블 모델을 구성하여 기존 모델과 성능 비교를 수행함.

### 2.2 합금 설계 기능 개선 방향 논의
- 기존 AI 자동 합금 생성 방식의 신뢰성과 물리적 제약 조건의 타당성 문제를 검토함.
- AI가 생성한 합금을 최종 결과로 제시하는 방식에서 벗어나, 사용자의 조건을 기반으로 후보 조성을 제안하고 판단 근거를 제공하는 의사결정 지원 방식으로 개발 방향을 수정함.

### 2.3 UI/UX 개선
- 기존 인터페이스의 입력 요소가 많아 사용이 어렵다는 문제를 개선하기 위해 간편 모드와 전문가 모드를 구분하는 방식으로 UI 구조를 개편함.
- 간편 모드에서는 핵심 운전 조건을 중심으로 크립 수명을 예측할 수 있도록 하고, 전문가 모드에서는 합금 조성과 세부 조건을 직접 설정할 수 있도록 구성함.
- 사용자 숙련도에 따른 접근성을 높이고 예측 결과 확인 과정을 단순화하는 방향으로 개선을 진행함.

## 3. 주요 의사결정 사항
- Histogram Gradient Boosting과 RBF Regression을 결합한 앙상블 모델을 개선 모델 후보로 선정하여 추가 검증하기로 결정함.
- 합금 설계 기능은 자동 생성 결과를 단순 제시하는 방식에서 사용자 조건 기반 후보 조성 및 판단 근거 제공 방식으로 전환하기로 함.
- 사용자 숙련도에 따라 간편 모드와 전문가 모드를 선택할 수 있도록 UI 구조를 개편하기로 함.

## 4. 리스크 및 대응
- 리스크 1: 앙상블 모델의 성능 향상이 제한적일 가능성
  - 대응: 모델별 성능 비교와 파라미터 조정을 반복하고 검증 데이터 기준의 신뢰성 평가를 수행함.
- 리스크 2: 후보 조성의 물리적 타당성 및 설명력 부족
  - 대응: 물리적 제약 조건을 적용하고 후보 조성의 추천 근거와 비교 정보를 함께 제공함.
- 리스크 3: 모드 구분에 따른 사용자 경험 복잡성 증가
  - 대응: 간편 모드의 입력 항목을 최소화하고 전문가 모드에는 세부 설정과 설명을 명확하게 구성함.

## 5. 차주 계획

### 5.1 개선 모델 검증
- Histogram Gradient Boosting과 RBF Regression 기반 앙상블 모델의 성능을 추가 검증함.
- 파라미터 조정을 통해 예측 정확도와 신뢰성을 지속적으로 개선함.

### 5.2 UI/UX 기능 구체화
- 간편 모드와 전문가 모드의 입력 항목 및 기능을 구체화함.
- 실제 크립 수명 예측 과정에서 사용자가 결과를 직관적으로 확인할 수 있도록 화면 구성과 시각화 방식을 개선함.

### 5.3 LLM/RAG 및 합금 설계 지원 기능 설계
- 로컬 LLM과 RAG에 활용할 프로젝트 데이터 및 전문자료의 구성 방식을 검토함.
- 사용자의 자연어 질문에서 필요한 조건을 추출하여 크립 수명 예측 모델 및 What-if API와 연결할 수 있는 구조를 설계함.
- 기존 합금과 후보 합금의 비교 정보를 제공하는 기능을 구체화함.

## 6. 기대 산출물
- 앙상블 모델 성능 비교 및 파라미터 조정 결과
- 간편 모드와 전문가 모드 UI 설계안
- LLM/RAG 연계 구조 및 자연어 질의 처리 설계안
- 기존 합금과 후보 합금 비교 기능 정의서
