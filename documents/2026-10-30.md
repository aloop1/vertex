# 회의록 (2026-10-30)

## 1. 회의 개요
- 프로젝트명: 크립 수명 예측을 위한 AI 솔루션
- 회의 목적: 시연 기반 기능 검증, 최종 실행본과 발표자료 정리 및 프로젝트 시연 영상 점검

## 2. 금주 진행 사항

### 2.1 시연 기반 기능 검증
- 대표 입력 사례를 활용하여 크립 수명 예측, 이미지 분석, LLM 질의응답 기능을 순차적으로 검증함.
- 입력 조건을 변경하거나 기능을 반복 실행했을 때 결과가 정상적으로 갱신되는지 확인함.
- 이전 결과가 남거나 표시가 지연되는 부분을 점검하여 보완함.

### 2.2 최종 실행본 및 발표자료 정리
- 최종 적용 모델과 웹페이지 코드, 실행 설정을 정리하고 기능 실행에 필요한 파일의 누락 여부를 확인함.
- 모델 파일과 코드 간 연결 경로를 점검함.
- 발표자료에 문제가 없는지 점검하며 과정을 정리함.

### 2.3 프로젝트 시연 영상 및 결과물 점검
- 시연 영상에 주요 기능의 입력 과정과 분석 결과가 명확하게 나타나는지 확인함.
- 모션 그래픽 품질을 높이기 위해 움직임을 자연스럽게 수정함.
- 영상 속 화면과 최종 실행본을 비교하여 기능 구성과 출력 내용의 일치 여부를 점검함.
- 주요 예측 결과와 화면 자료를 정리함.

## 3. 주요 의사결정 사항
- 검수 과정에서 확인한 보완 사항을 반영하고, 기능별 반복 실행으로 안정성을 확인하는 것으로 계획함.
- 발표 대본을 토대로 발표 스크립트를 정리하며 페어데이 발표를 준비하는 것으로 계획함.
- 최종 코드, 모델, 시연 영상과 주요 성능 결과를 정리하고 백업하는 것으로 계획함.
- 설치, 실행 방법과 기능별 사용 절차를 문서화하고, 모델의 적용 범위와 사용 시 유의사항을 정리하는 것으로 계획함.

## 4. 리스크 및 대응
- 리스크 1: 입력 조건 변경 및 반복 실행 시 이전 결과 잔존과 표시 지연
  - 대응: 결과 갱신 여부를 확인하고 해당 부분을 보완함. 차주에도 기능별 반복 실행을 통해 안정성을 확인하는 것으로 계획함.
- 리스크 2: 실행에 필요한 파일 누락 및 모델 파일과 코드 간 연결 경로 오류 가능성
  - 대응: 필요한 파일의 누락 여부와 연결 경로를 점검하고, 최종 코드와 모델 및 실행 설정을 정리함.
- 리스크 3: 시연 영상과 최종 실행본의 기능 구성 및 출력 내용 불일치 가능성
  - 대응: 영상 속 화면과 최종 실행본을 비교하고, 주요 예측 결과와 화면 자료를 정리함.
- 리스크 4: 프로젝트 산출물 보존 및 사용 절차 문서화 필요
  - 대응: 최종 산출물을 정리하고 백업하며, 설치와 실행 방법, 기능별 사용 절차 및 모델 사용 시 유의사항을 문서화하는 것으로 계획함.
