# 회의록 (2026-10-16)

## 1. 회의 개요
- 프로젝트명: 크립 수명 예측을 위한 AI 솔루션
- 회의 목적: KoMaP 이미지 분할 모델 성능 검증, 웹 기반 이미지 분석 기능 보완 및 크립 수명 예측 모델 성능 개선 결과 정리

## 2. 금주 진행 사항

### 2.1 KoMaP 이미지 분할 모델 성능 검증
- 데이터 증강과 학습 설정을 조정한 이미지 분할 모델의 검증 결과, mIoU 0.792를 달성함.
- 클래스별 IoU와 예측 마스크를 비교하여 각 상의 분할 성능을 확인함.
- 미세조직과 경계 영역에서 발생하는 오류를 검토함.

### 2.2 웹 기반 이미지 분석 기능 점검 및 보완
- 웹페이지에서 이미지 입력부터 예측 마스크 표시까지의 동작을 점검함.
- 원본 이미지와 분할 결과를 함께 비교할 수 있도록 웹페이지 화면을 보완함.
- 오버레이를 추가하여 이미지 분석 결과를 확인할 수 있도록 기능을 보완함.
- 이미지 크기에 따른 처리 및 결과 저장 과정을 확인함.

### 2.3 크립 수명 예측 모델 파인튜닝 및 성능 개선
- Histogram Gradient Boosting과 RBF Regression 기반 앙상블 모델의 주요 하이퍼파라미터와 결합 비중을 조정하여 성능을 개선함.
- R²를 기존 0.83에서 0.85까지 개선함.
- 온도, 응력, 합금 조성 조건에 따른 예측 오차를 비교하며 모델의 예측 정확도를 개선함.

## 3. 주요 의사결정 사항
- 최종 발표를 위해 크립 수명 예측, 이미지 분석, LLM 질의응답 기능의 입력부터 결과 출력까지 전체 동작을 검수하는 것으로 계획함.
- 주요 기능과 분석 결과를 명확하게 전달할 수 있도록 웹페이지 배치와 표시 항목을 조정하고, 예측값과 그래프 및 안내 문구의 가독성과 일관성을 점검하는 것으로 계획함.
- 최종 적용 모델의 성능 지표와 웹페이지 출력 결과의 일치 여부를 확인하고, 시연 환경의 모델 로딩과 응답 시간을 점검하는 것으로 계획함.
