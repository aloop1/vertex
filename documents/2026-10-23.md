# 회의록 (2026-10-23)

## 1. 회의 개요
- 프로젝트명: 크립 수명 예측을 위한 AI 솔루션
- 회의 목적: 주요 기능 통합 검수, 웹페이지 시각화 개선 및 모델 적용 결과와 시연 환경 점검

## 2. 금주 진행 사항

### 2.1 주요 기능 통합 검수 및 오류 수정
- 크립 수명 예측, 이미지 분석, LLM 질의응답 기능의 입력부터 결과 출력까지 전체 동작을 검수함.
- 입력값 누락과 잘못된 형식에 대한 처리 방식을 점검함.
- 기능별 결과 표시 및 화면 전환 과정에서 확인된 오류를 수정함.

### 2.2 웹페이지 구성 및 결과 시각화 개선
- 예측 결과와 분석 내용을 직관적으로 확인할 수 있도록 웹페이지의 배치와 표시 항목을 조정함.
- 예측 수명의 단위, 그래프의 축과 범례, 안내 문구를 정리함.
- 이미지 분석 화면의 원본, 분할 마스크, 오버레이 비교 방식과 가독성을 보완함.

### 2.3 모델 적용 결과 및 실행 환경 점검
- 크립 수명 예측 모델이 웹페이지에 정상적으로 적용되는지 확인함.
- 동일한 입력 조건에서 모델의 직접 예측값과 웹 출력값을 비교함.
- 시연 환경에서 모델 로딩과 기능별 응답 시간을 점검하고, 안정적인 실행을 위해 설정을 조정함.

## 3. 주요 의사결정 사항
- 대표 입력 사례를 활용한 최종 시연 시나리오에 따라 수명 예측, 이미지 분석, 질의응답 기능을 순차적으로 점검하는 것으로 계획함.
- 반복 실행과 조건 변경 시 결과 갱신 여부를 확인하고, 남아 있는 오류를 수정하는 것으로 계획함.
- 최종 모델과 코드, 실행 설정 및 필요한 파일을 정리하고, 시연용 영상과 최종 실행본의 주요 결과를 재점검하는 것으로 계획함.
