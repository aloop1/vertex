# 회의록 (2026-09-10)

## 1. 회의 개요
- 프로젝트명: 크립 수명 예측을 위한 AI 솔루션
- 회의 목적: 앙상블 모델 성능 개선, UI/UX 비교 기능 구체화 및 RAG 연계 방향 검토

## 2. 금주 진행 사항

### 2.1 새로운 앙상블 모델 성능 개선
- Histogram Gradient Boosting과 RBF Regression 기반 앙상블 모델의 주요 파라미터와 결합 비중을 조정하며 성능 개선을 진행함.
- 예측 오차가 큰 데이터의 온도, 응력, 합금 조성 조건을 분석하고, 특정 조건에서 오차가 집중되는 원인과 개선 방안을 논의함.

### 2.2 UI/UX 입력 및 결과 비교 방식 개선
- 간편 모드와 전문가 모드의 입력 항목을 정리하고, 예측 결과 확인 후 입력 조건을 변경하여 다시 비교할 수 있도록 화면 흐름을 구체화함.
- 기존 합금과 후보 합금의 조성 및 예측 수명을 함께 표시하여 조건 변화에 따른 차이를 확인할 수 있는 비교 화면을 설계함.

### 2.3 RAG 참고자료 선정 및 로컬 LLM 연계 검토
- RAG 활용 자료로 ‘Creep-Resistant Steels’와 크립 수명 예측 및 내열 합금 관련 논문을 선정함.
- 크립 발생 원리, 합금 원소의 영향, 온도와 응력에 따른 수명 변화 등을 중심으로 자료를 구성함.
- 로컬 LLM이 검색된 내용과 출처를 바탕으로 답변하도록 설계 방향을 논의함.

## 3. 주요 의사결정 사항
- 앙상블 모델의 결합 비중과 주요 파라미터를 조정하며 검증을 이어가기로 함.
- 간편 모드와 전문가 모드의 결과 화면에 기존 합금과 후보 합금 비교 기능을 포함하기로 함.
- RAG 참고자료는 크립 및 내열 합금 관련 전문자료 중심으로 구성하기로 함.

## 4. 리스크 및 대응
- 리스크 1: 특정 온도, 응력, 조성 조건에서 예측 오차 집중
  - 대응: 조건별 오차 분석과 파라미터 조정을 통해 취약 구간을 개선함.
- 리스크 2: 모드별 입력 항목 증가로 인한 사용성 저하
  - 대응: 간편 모드는 핵심 조건 중심으로 구성하고 세부 항목은 전문가 모드로 분리함.
- 리스크 3: RAG 답변의 근거 부족
  - 대응: 검색 자료의 출처를 함께 제공하고 전문자료 중심으로 검색 범위를 제한함.

## 5. 차주 계획

### 5.1 개선 모델 성능 및 일반화 검증
- 조정한 파라미터와 앙상블 결합 비중에 따른 성능을 비교함.
- 검증 데이터에서 예측 오차와 과적합 여부를 확인하고, 오차가 큰 조건을 중심으로 추가 개선을 진행함.

### 5.2 장재훈 교수님 면담
- 크립 수명 예측 모델의 활용 방향과 합금 설계 지원 기능의 타당성에 대한 의견을 구함.
- 관련 논문의 활용 범위와 결과 해석 시 고려해야 할 소재 분야의 주요 조건을 확인함.

### 5.3 로컬 LLM 응답 속도 측정 및 개선
- 로컬 환경에서 모델 크기와 양자화 설정에 따른 응답 속도를 비교함.
- 자료 검색부터 답변 생성까지 단계별 소요 시간을 확인하고, 검색 자료의 양과 입력 문맥 길이를 조정하여 대기 시간을 줄이는 실행 설정을 검토함.

## 6. 기대 산출물
- 앙상블 모델 파라미터 및 결합 비중별 성능 비교 결과
- 기존 합금과 후보 합금 비교 화면 설계안
- RAG 참고자료 목록 및 로컬 LLM 연계 구조
- 로컬 LLM 단계별 응답 시간 측정 결과

- 금주에는 앙상블 모델의 개선 방향과 사용자 중심 비교 화면을 구체화하고, 전문자료 기반 RAG와 로컬 LLM 연계 가능성을 검토함.
