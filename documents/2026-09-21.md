# 회의록 (2026-09-21)

## 1. 회의 개요
- 프로젝트명: 크립 수명 예측을 위한 AI 솔루션
- 회의 목적: KoMaP 경진대회용 이미지 분석 모델 착수, 로컬 LLM 운영성 및 모델 선정 근거 검토

## 2. 금주 진행 사항

### 2.1 KoMaP 경진대회용 모델 개발 착수
- 미세조직 이미지의 각 상을 분류하기 위해 ImageNet 사전학습 가중치를 적용한 인코더와 U-Net++ 디코더 기반 이미지 분할 모델 제작에 착수함.
- 여러 해상도의 특징을 활용하고, 각 픽셀을 Primary Si, Al3Ni, Eutectic Si, Al의 4개 상으로 분류하도록 기본 학습 구조를 구성함.

### 2.2 로컬 LLM 응답 지연에 따른 개발 방향 검토
- 로컬 LLM의 응답 속도가 느려 실제 서비스 이용 시 대기 시간이 길어지는 문제를 확인함.
- 모델 경량화, 입력 문맥 축소, 검색 자료 수 조정 등 속도 개선 방안을 검토함.
- 실행 환경의 한계를 고려하여 외부 API 활용을 포함한 대안과 기능 구현 범위를 논의함.

### 2.3 발표 피드백 기반 모델 선정 근거 검토
- 발표 후 모델 변경 이유를 성능 향상만으로 설명하기에는 부족하다는 피드백을 받음.
- 데이터 규모와 정형 데이터의 특성, 변수 간 비선형 관계를 모델 구조와 연결하여 선정 근거를 보강하는 방향을 논의함.
- Histogram Gradient Boosting의 성능이 높은 이유와 기존 Transformer 계열 모델의 성능이 낮았던 원인을 학습 방식 및 과적합 가능성 측면에서 검토함.

## 3. 주요 의사결정 사항
- KoMaP 모델은 ImageNet 사전학습 인코더와 U-Net++ 디코더 기반 이미지 분할 구조로 개발을 진행하기로 함.
- 로컬 LLM은 경량화와 양자화 성능을 비교한 뒤 외부 API 활용 여부를 결정하기로 함.
- 모델 선정 발표에서는 성능뿐 아니라 데이터 구조, 변수 관계, 학습 방식, 과적합 가능성을 함께 설명하기로 함.

## 4. 리스크 및 대응
- 리스크 1: 미세조직 상 간 경계 및 유사 영역 분류 오류
  - 대응: 클래스별 IoU와 예측 마스크를 확인하고 경계 영역 중심으로 전처리와 학습 설정을 개선함.
- 리스크 2: 로컬 LLM 응답 지연으로 인한 사용성 저하
  - 대응: 경량 모델, 양자화, 문맥 길이, 검색 자료 수를 비교하여 실행 설정을 최적화함.
- 리스크 3: 모델 변경 근거에 대한 발표 설득력 부족
  - 대응: 동일한 데이터 분할과 평가 기준으로 모델별 성능을 비교하고 데이터 특성과 모델 구조의 관계를 정리함.

## 5. 차주 계획

### 5.1 KoMaP 경진대회용 모델 학습 및 결과 분석
- 기본 모델 학습을 진행하고 클래스별 IoU와 예측 마스크를 확인함.
- 구분이 어려운 상과 경계 영역의 오류를 분석하여 전처리 및 학습 설정의 개선 방향을 도출함.

### 5.2 로컬 LLM 속도 개선 방안 비교
- 경량 모델과 양자화 설정, 입력 문맥 길이에 따른 응답 속도 및 답변 품질을 비교함.
- 비교 결과를 바탕으로 로컬 실행 유지 여부와 외부 API 활용 가능성을 검토하여 구현 방향을 구체화함.

### 5.3 모델별 성능 차이 분석 및 선정 근거 보강
- 동일한 데이터 분할과 평가 기준에서 기존 Transformer 계열 모델과 현재 앙상블 모델의 성능을 비교함.
- 학습 및 검증 성능 차이와 데이터 규모에 따른 변화를 확인함.
- Histogram Gradient Boosting 단독 모델과 RBF Regression 결합 모델을 비교하여 각 구성 요소의 기여도를 분석함.
