# 회의록 (2026-10-01)

## 1. 회의 개요
- 프로젝트명: 크립 수명 예측을 위한 AI 솔루션
- 회의 목적: KoMaP 이미지 분할 모델 성능 개선, 프로젝트 기능 연동 및 로컬 LLM 실행 환경 검토

## 2. 금주 진행 사항

### 2.1 KoMaP 경진대회용 이미지 분할 모델 성능 개선
- 이미지 분할 모델을 기반으로 학습 및 성능 개선 작업을 진행함.
- 미세조직의 세부 형태를 보존하기 위해 원본 해상도를 유지한 패치 기반 학습을 적용함.
- 회전, 반전, 밝기, 대비 조절을 통한 데이터 증강을 구성함.
- 클래스 불균형을 고려한 가중 손실과 IoU 개선을 위한 손실 함수를 결합하고, 미세조직의 분류 정확도를 높이기 위한 모델 개선을 지속함.

### 2.2 이미지 분할 모델의 프로젝트 적용 진행
- 구축한 이미지 분할 모델을 기존 크립 수명 예측 프로젝트에 적용하는 작업을 진행함.
- 미세조직 이미지 분석 기능을 프로젝트 내에서 활용할 수 있도록 웹페이지에 추가하여 모델 연동과 기능 통합을 추진함.

### 2.3 로컬 LLM 화면 개발 및 실행 환경 검토
- 로컬 LLM을 활용한 질의응답 화면 개발을 완료함.
- 응답 속도 지연 문제가 지속되어 화면 개발과 별도로 실행 환경 개선이 필요함을 확인함.
- 응답 속도 확보를 위해 높은 사양의 컴퓨터를 활용하는 방향으로 실행 환경 변경을 논의함.

## 3. 주요 의사결정 사항
- KoMaP 이미지 분할 모델은 클래스별 IoU와 예측 마스크를 바탕으로 오류를 분석하고, 데이터 증강과 학습 설정을 조정하여 성능 개선을 추진함.
- 이미지 분할 기능의 프로젝트 적용을 이어서 진행하고, 이미지 입력부터 분할 결과 표시까지 전체 동작을 검증하는 방향으로 계획을 수립함.
- 로컬 LLM은 실행 환경 변경을 논의하고, 기존 환경과의 응답 속도 비교를 통해 개선 여부를 확인하는 방향으로 계획을 수립함.
